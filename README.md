# Лабораторная работа № 4. Написание модульных тестов

## План тестирования

### 1. Цели и задачи

Проверить правильность вычисления площади и периметра прямоугольника. Для этого нужно подобрать входные данные, рассчитать ожидаемые значения вручную, сравнить их с ответами программы и автоматизировать проверки средствами `unittest`.

### 2. Описание тестируемого продукта

Модуль [rectangle.py](rectangle.py) содержит две функции. Обе принимают длины сторон прямоугольника `a` и `b`.

| Функция | Результат | Формула |
| --- | --- | --- |
| `area(a, b)` | Площадь | `S = a × b` |
| `perimeter(a, b)` | Периметр | `P = 2 × (a + b)` |

### 3. Область тестирования

Проверяются функции `area` и `perimeter` на четырёх наборах данных: разные целые стороны, равные стороны, одна нулевая сторона и стороны с дробным значением. Передача нулевой стороны проверяет результат вычисления на граничном значении, предусмотренном в задании.

### 4. Стратегия тестирования

Сначала для каждого набора ожидаемые значения вычисляются по формулам. Затем функции вызываются в Python, а их ответы сравниваются с ручными расчётами. Для повторной проверки используются восемь модульных тестов в файле [test_rectangle.py](test_rectangle.py), по четыре на каждую функцию.

Тесты написаны в классе `RectangleTestCase`, унаследованном от `unittest.TestCase`. Имена методов начинаются с `test_`. Целые результаты проверяются через `assertEqual`, а результаты для дробных входных данных — через `assertAlmostEqual`.

### 5. Критерии приёмки

- Для всех четырёх наборов входных данных площадь и периметр совпадают с ожидаемыми значениями.
- При автоматическом запуске выполняются все восемь тестов, итоговый статус — `OK`.

### 6. Ожидаемые результаты

По итогам проверки должны быть готовы таблица ручных расчётов, файл с восемью тестами и протокол их запуска. Ожидается, что все восемь тестов пройдут успешно. При обнаружении дефекта в протоколе фиксируются функция, входные данные, ожидаемое и фактическое значения.

## Ручное тестирование

Из каталога проекта интерпретатор запущен командой `python3`. Для проверки прямоугольника со сторонами 3 и 5 использованы следующие команды Python.

```python
from rectangle import area, perimeter

print("Площадь =", area(3, 5), "Периметр =", perimeter(3, 5))
```

Вывод для этого набора данных.

```text
Площадь = 15 Периметр = 16
```

Остальные наборы проверены вызовами тех же функций с соответствующими аргументами.

| Случай | Стороны | Площадь по формуле | Площадь в программе | Периметр по формуле | Периметр в программе | Статус |
| --- | --- | --- | --- | --- | --- | --- |
| Разные стороны | 3 и 5 | 3 × 5 = 15 | 15 | 2 × (3 + 5) = 16 | 16 | Пройден |
| Квадрат | 10 и 10 | 10 × 10 = 100 | 100 | 2 × (10 + 10) = 40 | 40 | Пройден |
| Нулевая сторона | 10 и 0 | 10 × 0 = 0 | 0 | 2 × (10 + 0) = 20 | 20 | Пройден |
| Дробная сторона | 2,5 и 4 | 2,5 × 4 = 10 | 10.0 | 2 × (2,5 + 4) = 13 | 13.0 | Пройден |

## Автоматическое тестирование

Среда выполнения — macOS, Python 3.14.7. Команда запуска из каталога проекта приведена ниже.

```bash
python3 -m unittest -v test_rectangle
```

Итоговый вывод `unittest`.

```text
----------------------------------------------------------------------
Ran 8 tests in 0.000s

OK
```

Все восемь тестов прошли успешно. В проверенных случаях расхождений между ручными расчётами и результатами функций не обнаружено.
